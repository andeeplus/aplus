# Programs

A program is one tracking issue plus its child issues, in order.

- **The tracking issue** states the goal, the scope and non-goals, and when it is done.
- **Each child** is one issue at the chosen size, ordered by "blocked by". The order becomes a PR stack ([create-pr: stacks](../../create-pr/references/stacks.md)).
- **A question to answer first** is a decision issue in the program. Work it blocks waits for a maintainer's answer.
- **Done** when every child issue is closed. Close the tracking issue by hand, asking first.
