# Programs

A program is one tracking issue plus one child issue per change.

- **The tracking issue** states the goal, the scope and non-goals, and when it is done.
- **Each change** is its child, ordered by "blocked by". The order becomes a PR stack ([create-pr: stacks](../../create-pr/references/stacks.md)).
- **A question to answer first** is a decision issue in the program. Work it blocks waits for a maintainer's answer.
- **Done** when every change is closed. Close the tracking issue by hand, asking first.
