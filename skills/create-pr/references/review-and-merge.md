# Review and merge

- **Answer a review:** fix on the branch, run [final-review](../../final-review/SKILL.md), commit with [commit-expert](../../commit-expert/SKILL.md), ask, push. Reply on each thread with what changed, and leave resolving it to the reviewer.
- **Merge only when asked,** with the project's merge method. A stack merges as a whole, with the host skill's stack steps.
- **Close the issues the merge left open,** each with a comment naming the PR. The host skill says which issues a merge closes.
