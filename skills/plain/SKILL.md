# Plain

A brief names the outcome for someone familiar with the area. A primer explains the same change for someone unfamiliar with it, adding only the context needed to understand it.

## Rules

- **Keep the facts consistent.** Lead each version with what changes. Ground the primer's context in the same evidence as the brief.
- **Explain what matters.** Use short sentences and preserve the real names of skills, commands and project terms. Explain an unfamiliar term only when its meaning is needed to understand the change; prefer explaining the behaviour and its consequence.

```md
## Brief

...

## Primer

...
```
