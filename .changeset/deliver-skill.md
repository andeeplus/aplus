deliver: take an idea, a ticket or a program of issues to pull requests ready to merge. For a new ticket or idea, triage or define runs first and the user reviews the spec and its issue drafts; then the build, final-review and the PR run automatically, issue after issue, asking only before a dangerous action. An issue that cannot go on is parked and the run continues. The run ends with the drafts for deferred findings in its output, created once the user approves them.
